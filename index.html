1. Toplanan Veriler

Bu uygulama mümkün olduğunca cihaz-içi çalışacak şekilde tasarlanmıştır. Temel kullanımda kişisel veri toplamaz.

1.1 Yerel Depolama (Cihazınızda Kalır)

  • Kaldığınız yer
  • Hangi sure ve ayette kaldığınız bilgisi
  • Favori sure/ayetler
  • Ayarlar (tema, yazı boyutu vb.)
  • Arama geçmişi

Bu veriler cihazınızda saklanır ve uygulama deneyimini geliştirmek için kullanılır.

1.2 API İstekleri

Uygulama, Kur’an metinlerini çekmek için Açık Kuran API kullanır:

https://api.acikkuran.com

Gönderilen veri yalnızca istenen sure/ayet numarası gibi teknik isteklerden ibarettir.

1.3 Firebase Hizmetleri (Opsiyonel)

Uygulamada aşağıdaki Firebase servisleri opsiyonel olarak kullanılabilir:

  • Firebase Analytics: anonim kullanım istatistikleri
  • Firebase Crashlytics: hata raporları
  • Firebase Authentication: giriş yapan kullanıcılar için kimlik doğrulama

2. Veri Kullanımı

Toplanan veriler şu amaçlarla kullanılabilir:

  • Uygulama işlevselliğini sağlamak
  • Kullanıcı deneyimini iyileştirmek
  • Hata düzeltmek
  • Bulut yedekleme sağlamak (yalnızca giriş yapan kullanıcılar için)

Veriler:

  • Satılmaz
  • Ticari amaçla paylaşılmaz
  • Reklam amacıyla kullanılmaz
  • Profil oluşturmak için kullanılmaz

3. Veri Saklama

Yerel Veriler

  • Nerede: Cihazınızın dahili hafızası
  • Ne kadar: Uygulamayı silene kadar
  • Yedekleme: Manuel olabilir

Cloud Veriler (Sadece Giriş Yapmış Kullanıcılar)

  • Nerede: Google Cloud / Firebase
  • Ne kadar: Hesabınızı silene kadar
